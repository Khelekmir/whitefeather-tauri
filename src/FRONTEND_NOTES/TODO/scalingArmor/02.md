## ✅ Goal

Enhance your **layer scaling** by **reducing durability damage for inner layers more if outer layers are made from stronger material**.

This models realistic behavior:

* A **steel breastplate** should absorb nearly all impact, sparing the shirt underneath.
* But if you’re wearing **cloth over cloth**, both layers should be somewhat affected.

---

## 🔧 Step-by-Step Implementation

We'll:

1. Determine outermost material's strength (or durability).
2. Use it to reduce how much damage passes through to inner layers.
3. Apply a scaling multiplier in the durability loss formula.

---

### 🧮 Formula: Layer Scaling with Material Absorption

Let’s define a multiplier like this:

```js
layerScaling = baseLayerFactor * bleedThroughFactor;
```

Where:

* `baseLayerFactor`: falls off with index (`1.0`, `0.5`, `0.25`…)
* `bleedThroughFactor`: how much *passes through* based on outer layer material

---

### 🔁 Modified Loop in `resolveTestAttack`

Replace your existing loop with something like this:

```js
const assignments = bodypartArmorAssignments[mainhandBodypartHit] || [];

const outermostSlot = assignments[0];
const outerItem = defender[outermostSlot];
const outerMaterialKey = outerItem?.combatStats?.itemType || "cloth";
const outerMaterial = equipmentMaterial[outerMaterialKey] || equipmentMaterial["cloth"];

assignments.forEach((slot, index) => {
    const item = defender[slot];
    if (!item || item.itemType !== "armor") return;

    const materialKey = item.combatStats?.itemType || "cloth";
    const material = equipmentMaterial[materialKey] || equipmentMaterial["cloth"];

    const layerDepth = index;
    const baseLayerFactor = 1 / Math.pow(2, layerDepth); // 1.0, 0.5, 0.25...

    // Bleed-through reduced by outer material durability
    const bleedThroughFactor = 1 - (outerMaterial.durability / 10); // 0.9 for cloth, 0.1 for adamantite

    // Combine both
    const layerScaling = layerDepth === 0 ? 1 : baseLayerFactor * bleedThroughFactor;

    const loss = calcArmorDurabilityLoss(item, attackValue, layerScaling);
    const newDurability = Math.max(
        0, roundToThousandths(item.combatStats.durability - loss)
    );

    updatedEquipment[slot] = {
        ...item,
        combatStats: {
            ...item.combatStats,
            durability: newDurability
        }
    };
});
```

> ❗ Note: If `outerMaterial.durability` is `10` (adamantite), then `bleedThroughFactor` = `0`, so no damage passes to inner layers. If it's `1` (cloth), then `bleedThroughFactor` = `0.9`, so inner layers take nearly full damage scaling.

### ✅ Adjusted `calcArmorDurabilityLoss`

No change needed except it accepts the new `layerScaling`:

```js
export function calcArmorDurabilityLoss(item, attackerAtkValue, layerScaling = 1) {
    const material = equipmentMaterial[item.combatStats.itemType] || equipmentMaterial.cloth;
    const sizeMultiplier = armorSizeMultipliers[item.itemSlot] || 1;
    
    const baseLoss = ((attackerAtkValue / sizeMultiplier) / (material.durability)) / 20;
    const scaledLoss = baseLoss * layerScaling;

    return Math.min(item.combatStats.durability, roundToThousandths(scaledLoss));
}
```

## 🧠 Optional Tweaks

* **Tunable softness factor**: If `cloth` and `leather` should always allow *some* bleed, even under strong metal, consider capping `bleedThroughFactor`:

  ```js
  const minBleed = 0.15; // minimum pass-through
  const bleedThroughFactor = Math.max(minBleed, 1 - (outerMaterial.durability / 10));
  ```

* **Hybrid strength + durability**: Consider blending strength and durability:

  ```js
  const bleedThroughFactor = Math.max(minBleed, 1 - ((outerMaterial.durability + outerMaterial.strength) / 20));
  ```
