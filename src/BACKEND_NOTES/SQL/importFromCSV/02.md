You're welcome — here's a full, clean **Java utility method** that reads from a `CSV` file and inserts rows into the `public.armor` table using JDBC. It will be easy to adapt for other tables later.

---

### ✅ Assumptions

* Your CSV file is located at:
  `backend/src/main/resources/data/armor.csv`
* It does **not** contain a header row.
* It contains values in this order:

```text
item_name, armor_type, equipment_slot, armor_description,
dodge_bonus, parry_bonus, block_bonus, armor_bonus,
resist_bonus, allure_bonus, charisma_bonus,
armor_durability, armor_degradation_rate, flags, armor_weight
```

---

### ✅ Java Code (place inside your `DatabaseScriptRunner` class or a new one)

```java
package practice.feproj.backend.utility;

import java.io.BufferedReader;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.nio.file.Paths;
import java.sql.*;
import java.util.ArrayList;
import java.util.List;

public class ArmorCsvImporter {

    private static final String CSV_PATH = "backend/src/main/resources/data/armor.csv";

    public static void importArmorCsv() {
        Path path = Paths.get(CSV_PATH);

        String insertSQL = """
                INSERT INTO public.armor (
                    item_name,
                    armor_type,
                    equipment_slot,
                    armor_description,
                    dodge_bonus,
                    parry_bonus,
                    block_bonus,
                    armor_bonus,
                    resist_bonus,
                    allure_bonus,
                    charisma_bonus,
                    armor_durability,
                    armor_degradation_rate,
                    flags,
                    armor_weight
                ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?::jsonb, ?)
            """;

        try (
            Connection conn = DatabaseConnector.createConnection();
            BufferedReader reader = Files.newBufferedReader(path);
            PreparedStatement ps = conn.prepareStatement(insertSQL)
        ) {
            conn.setAutoCommit(false);
            String line;
            int lineNumber = 0;

            while ((line = reader.readLine()) != null) {
                lineNumber++;
                // Skip blank lines
                if (line.trim().isEmpty()) continue;

                List<String> fields = parseCsvLine(line);

                if (fields.size() != 15) {
                    System.err.println("Skipping line " + lineNumber + ": Incorrect number of fields.");
                    continue;
                }

                for (int i = 0; i < fields.size(); i++) {
                    String value = fields.get(i).trim().replaceAll("^'+|'+$", ""); // Strip single quotes

                    switch (i) {
                        case 0, 1, 2, 3 -> ps.setString(i + 1, value); // Strings
                        case 4, 5, 6, 7, 8, 9, 10 -> ps.setDouble(i + 1, Double.parseDouble(value)); // Doubles
                        case 11, 12 -> ps.setDouble(i + 1, Double.parseDouble(value)); // More doubles
                        case 13 -> ps.setString(i + 1, value); // JSONB
                        case 14 -> ps.setDouble(i + 1, Double.parseDouble(value)); // weight
                    }
                }

                ps.addBatch();
            }

            ps.executeBatch();
            conn.commit();
            System.out.println("Armor CSV import completed.");

        } catch (SQLException | IOException e) {
            System.err.println("Error during CSV import:");
            e.printStackTrace();
        }
    }

    // A basic CSV line parser that handles quoted strings and commas inside quotes
    private static List<String> parseCsvLine(String line) {
        List<String> result = new ArrayList<>();
        StringBuilder current = new StringBuilder();
        boolean inQuotes = false;

        for (char c : line.toCharArray()) {
            if (c == ',' && !inQuotes) {
                result.add(current.toString());
                current.setLength(0);
            } else if (c == '"') {
                inQuotes = !inQuotes;
            } else {
                current.append(c);
            }
        }
        result.add(current.toString()); // Add last field
        return result;
    }
}
```

### 🧠 Tips

* You can make this more generic by passing the table name, column list, and file path.
* Use `PreparedStatement.setObject()` for general-purpose handling.
* Make sure the JSON field (`flags`) is valid JSON — wrap keys in double quotes in the CSV:

  ```csv
  '{"prf":"Amberyl","indestructible":true,"unequipped":true}'
  ```
