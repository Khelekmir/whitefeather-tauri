**Temperament Assessments for Lyn's Story Characters**

These assessments map each character to one of the **12 temperament blends** (primary-secondary) based on the classical four temperaments model:
- **Sanguine** (sociable, impulsive, fun-loving, charismatic).
- **Choleric** (ambitious, dominant, passionate, quick-tempered).
- **Melancholic** (analytical, moody, perfectionist, sensitive).
- **Phlegmatic** (relaxed, peaceful, reliable, observant).

Assignments draw from detailed personality analyses via game scripts, supports, and wiki summaries—focusing on core traits like extroversion, drive, moodiness, and calmness.
