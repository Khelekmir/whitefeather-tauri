Yeah, this is a thoughtful design question — it’s about making your durability system feel **logical and satisfying** to players, with a layer-aware model that simulates **damage absorption through layered armor**. Here's how you can approach this problem in a way that's both flexible and extensible.

---

## 🔥 Goal Recap

You want:

* Armor pieces **closer to the outermost layer** (e.g. breastplate) to absorb **most or all** of the durability damage.
* Inner layers (e.g. shirt, undershirt) to absorb **less durability damage**, based on their **index** in the layer list.
* Ensure **correct handling** for body parts with only one layer of armor.
* Prevent weirdness like a shredded undershirt under a pristine breastplate.

---

## ✅ Suggested Plan

### 1. **Update `resolveTestAttack` to pass index-based damage weight**

Instead of treating all armor layers equally, compute a **durability loss modifier** based on the armor’s position in the layer list.

### 2. **Add layer-based scaling inside `resolveTestAttack`**

Here's how:

```js
const assignments = bodypartArmorAssignments[mainhandBodypartHit] || [];

assignments.forEach((slot, index) => {
    const item = defender[slot];
    if (!item || item.itemType !== "armor") return;

    const layerDepth = index; // 0 = outermost, 1 = middle, 2 = innermost
    const layerCount = assignments.length;

    // Damage reduction per layer — outermost gets full, inner gets less.
    const layerScaling = 1 / Math.pow(2, layerDepth); // e.g., 1, 0.5, 0.25
    // or: const layerScaling = (layerCount - index) / layerCount;

    const loss = calcArmorDurabilityLoss(item, attackValue, layerScaling);
    const newDurability = Math.max(
        0, roundToThousandths(item.combatStats.durability - loss)
    );

    updatedEquipment[slot] = {
        ...item,
        combatStats: {
            ...item.combatStats,
            durability: newDurability
        }
    };
});
```

---

### 3. **Update `calcArmorDurabilityLoss` to accept a scaling factor**

Add a second parameter `layerScaling = 1` to the function:

```js
export function calcArmorDurabilityLoss(item, attackerAtkValue, layerScaling = 1) {
    const material = equipmentMaterial[item.combatStats.itemType] || equipmentMaterial.cloth;
    const sizeMultiplier = armorSizeMultipliers[item.itemSlot] || 1;
    
    const baseLoss = ((attackerAtkValue / sizeMultiplier) / (material.durability)) / 20;
    const scaledLoss = baseLoss * layerScaling;

    return Math.min(item.combatStats.durability, roundToThousandths(scaledLoss));
}
```

---

### 📊 Layer Scaling Options

You can tweak this line:

```js
const layerScaling = 1 / Math.pow(2, layerDepth);
```

Alternative formulas:

| Formula                             | Meaning                                           |
| ----------------------------------- | ------------------------------------------------- |
| `1 / Math.pow(2, layerDepth)`       | Halves each deeper layer’s share (1.0, 0.5, 0.25) |
| `(layerCount - index) / layerCount` | Linear falloff (3 layers = 1.0, 0.66, 0.33)       |
| `1 if index === 0 else 0`           | Only outer layer takes damage                     |

Which you choose depends on **how forgiving** you want to be toward inner armor.

### 🧠 Optional Enhancements

* Make `layerScaling` also consider material softness. Maybe soft layers absorb *even less*.
* Add a boolean to armor like `absorbsLayeredDamage: true | false` to exempt special armor types.
* Visual debugging: Log each armor slot’s `durability`, `layerScaling`, and `newDurability`.

## ✅ Summary

Update your damage loop to:

1. Look at `bodypartArmorAssignments[hitBodypart]`.
2. For each layer, calculate a **layer-based scaling factor**.
3. Pass it into `calcArmorDurabilityLoss(item, atkValue, scalingFactor)`.
4. Reduce durability based on that scaled value.

This gives you a **rich, physically-intuitive layering system** where outer armor takes the brunt and inner layers are only slightly worn — unless that’s all that’s there.
